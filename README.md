# Problema de las 3 Puertas

Juego web interactivo basado en el problema de Monty Hall. El jugador elige una
de tres puertas y decide si conserva su elección o cambia después de que el
presentador revele una cabra.

## Características

- Selección interactiva entre tres puertas.
- Imágenes para las puertas, las cabras y el automóvil.
- Opción de conservar o cambiar la elección.
- Contador de partidas ganadas y perdidas.
- Diseño adaptable hecho con CSS.

## Cómo usarlo

1. Descarga o clona el repositorio.
2. Abre `index.html` en un navegador.
3. Elige una puerta y decide si quieres quedarte o cambiar.

## Estructura

- `index.html`: estructura de la página.
- `style.css`: diseño y estados visuales.
- `script.js`: lógica del juego.
- `img/`: imágenes utilizadas por el juego.

## Tecnologías

HTML, CSS y JavaScript.
